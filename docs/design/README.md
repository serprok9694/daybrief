## Визуальная система

- **Стекло в духе visionOS** поверх фото интерьера. Два слоя: большая панель `sheet` (radius 40) и карточки-виджеты `card` (radius 28) внутри неё. Текст всегда лежит на карточке или панели, никогда прямо на фоне.
- **Палитра:** тёплые нейтральные цвета, primary-кнопка чёрная (в тёмной теме инвертирована: светлая плашка, тёмный текст), **один акцент** — оранжевый — только для «сейчас / важно».
- **Шрифт:** Manrope 400 / 500 / 700 (латиница + кириллица). Иконки — Lucide, stroke 1.75.
- **Фон по времени суток:** morning 05–11, day 11–17, evening 17–22, night 22–05 + ручной выбор в настройках. В макетах фоны — CSS-заглушки (`.sc-*`); реальные фото подставляются через `--scene-photo` и ещё не выбраны.
- **Тема:** светлая / тёмная. Тёмная естественно сочетается с вечерним и ночным фоном. По умолчанию следует системной; в настройках — переключатель «Авто / Светлая / Тёмная» (см. «Решения по открытым вопросам»).

### Доступность (обязательно сохранить при реализации)

- Контраст проверен на **худшем фоне** темы (светлая — на ночном, тёмная — на дневном): все текстовые пары ≥ 4.5:1 (ink 11.7 / 9.1, ink-2 6.8 / 7.0, ink-3 5.3 / 5.4, акцентный чип 5.1 / 4.8). Если на реальном фото контраст падает — **уплотнять плашку**, не осветлять текст.
- Состояния не только цветом: просрочено = чип с иконкой часов + текст; нужен ответ = иконка «ответить» + текст; следующее событие = сплошной чип с текстом «через N мин».
- Зоны нажатия ≥ 44 px (у кнопок-иконок 36 px видимых + расширение хит-зоны).
- У иконочных кнопок есть `aria-label` / `accessibilityLabel`; анимации skeleton / orb / spin отключаются при `prefers-reduced-motion` / Reduce Motion.

## Раскладка

### Desktop (≥ 701 px, макет 1440)

```
[ rail 0px (резерв под навигацию) | main ]
main:
  верхняя панель (стекло, pill, h 64): аватар + имя → настройки | командная строка (max 560) | колокольчик
  sheet (padding 44, gap 24):
    приветствие «Good morning, {name}» + дата
    AI-сводка (во всю ширину)
    сетка: События | Задачи | Письма   (auto-fit, min 340, gap 20, карточки одной высоты в ряду)
    Идея дня (во всю ширину, текст слева, кнопки справа)
```

- Колонка навигации уже есть в сетке страницы (`--rail-w`, в v1 = 0) — добавление навигации не потребует переделки.
- Отступы страницы 24 / 40 px.

### Mobile (≤ 700 px, макет 390)

- Одна колонка, порядок тот же. Панель сверху: аватар + имя + колокольчик.
- **Командная строка закреплена внизу** (sticky, 12 px от края, h 60) — в зоне большого пальца. Контенту нужен нижний отступ под неё.
- sheet: padding 16, radius 32, gap 14; карточки: padding 18.
- На Android использовать `.lite`-параметры стекла.

## Экраны

- **Вход:** логотип (orb + «daybrief»), заголовок «Весь твой день за десять секунд», кнопка «Войти через Google» (чёрная, с цветным знаком G на белом квадрате), три пункта о приватности (только чтение; почта подключается отдельно; тексты писем не храним), переключатель EN/RU.
- **Настройки** (вход через аватар): Язык (сегмент English / Русский) · Фон (Авто + 4 сцены, превью) · Подключённые аккаунты (Google Календарь+Задачи — подключено/отключить; Gmail — подключить) · API-токены (список с маской `dbf_••••a91c` и «использован …», «Новый токен», «Отозвать», подсказка `POST /ideas`).

## Заметки для реализации (Expo + NativeWind)

- Токены вынести в `packages/ui/tokens` из `tokens.json`; цвета в Tailwind ссылаются на CSS-переменные (`ink: "var(--ink)"` и т. п., см. витрину токенов), тема переключается классом / `vars()` NativeWind v4 на корне.
- Стекло: web — `backdrop-filter: blur() saturate()`; iOS/Android — `expo-blur` (`BlurView`, `tint` light/dark) + полупрозрачная плашка поверх с теми же alpha. На Android брать `.lite`.
- Шрифт: `@expo-google-fonts/manrope` (400, 500, 700). Иконки: `lucide-react-native` / `lucide-react`.
- Брейкпоинт мобильной раскладки: 700 px.
- i18n: строки — в `i18n.json`; русские на 20–30 % длиннее, в макетах проверены заголовки, кнопки и чипы на обоих языках.
- Данные в макетах — образцы, не контракт API.

## Решения по открытым вопросам (2026-10-27)

1. **Фото сцен.** В M0 — CSS-градиенты из макетов (`.sc-*`). Четыре лицензионно чистых фото (например, Unsplash) подбираются отдельной задачей позже и подставляются через `--scene-photo` без изменений кода.
2. **Тема.** По умолчанию — системная. В настройках — сегмент «Авто / Светлая / Тёмная» (добавить в экран настроек рядом с языком; строки `settings.theme.*` дописать в `i18n.json`).
3. **Шапка.** Как в макете: в верхней панели только имя, полное приветствие — в заголовке.
4. **Колокольчик.** В v1 **не показываем** — уведомлений нет. Место в правой части шапки остаётся под него.
