# daybrief — бриф для Claude Design

## Что делаем

**daybrief** — персональный дашборд «мой день». Пользователь открывает его утром и за 10 секунд понимает свой день: AI-сводка, события, задачи, важные письма и одна идея, к которой стоит вернуться. В будущем это лицо персонального ассистента в духе Jarvis, поэтому дизайн должен ощущаться спокойным, премиальным и «живым».

Полный контекст продукта — `docs/PRD.md`.

## Что нужно на выходе

1. **Дашборд** — десктоп (1440) и мобильный (390) варианты, светлая и тёмная тема.
2. **Состояния каждого виджета:** загрузка (skeleton), данные, пусто, ошибка, «не подключено».
3. **Экран входа** (Sign in with Google).
4. **Настройки** (минимально): язык, фон, подключённые аккаунты, API-токены для Shortcuts.
5. **Дизайн-токены:** цвета, типографика, радиусы, тени, параметры стекла (blur, прозрачность, обводка) — для обеих тем.
6. **Набор компонентов:** карточка-виджет, командная строка, кнопки (primary / secondary / ghost), чип-статус, элемент списка, аватар, skeleton.

## Визуальное направление

Референсы: `references/ref-overview.webp`, `references/ref-savings-goals.webp`.

Берём из референсов:
- **Стекло в стиле visionOS:** матовые полупрозрачные панели с размытием поверх фотографии интерьера.
- **Тёплая нейтральная палитра** (бежевый, песочный, белый), **чёрные** primary-кнопки, **один акцентный цвет** (в референсе — оранжевый) для «сейчас» / «важно».
- Крупные радиусы, много воздуха, крупный заголовок-приветствие.
- Верхняя панель: аватар + приветствие слева, **командная строка с AI-иконкой по центру**, колокольчик справа.

**Не** берём:
- Левую иконочную навигацию и нижнюю панель табов — в v1 один экран. Оставить место, чтобы добавить навигацию позже без переделки сетки.
- Графики и финансовые метрики — у нас списки и текст.

### Фон по времени суток

Фон меняется в зависимости от времени: **утро / день / вечер / ночь** (тёплая фотография интерьера в соответствующем свете). Пользователь может выбрать фиксированный фон из набора. Тёмная тема естественно сочетается с вечерним и ночным фоном («дымчатое стекло»).

### Доступность

- Контраст текста на стекле — **WCAG AA** в обеих темах и на всех четырёх фонах. Если нужно — уплотнять подложку стекла, а не жертвовать читаемостью.
- Состояния не передаются только цветом (иконка или текст рядом).

## Структура дашборда

Порядок по важности (сверху вниз / слева направо):

1. **Верхняя панель:** аватар (→ настройки), «Good morning, {name}», командная строка, колокольчик.
2. **Приветствие + дата**, под ним **AI-сводка дня** — 2–3 предложения. Главный элемент экрана.
3. **События сегодня** — таймлайн; текущее/следующее событие выделено акцентом; время, название, длительность, иконка видеозвонка (Meet/Zoom) если есть.
4. **Задачи** — на сегодня + просроченные (просроченные помечены); чекбоксов нет (v1 только читает).
5. **Важные письма** — аватар/инициалы отправителя, имя, тема, выжимка 1–2 строки, чип «Нужен ответ».
6. **Идея дня** — текст идеи, предложение AI («У тебя свободно 14:00–16:00 — может, поисследовать?»), кнопки **«Не сейчас»** и **«Готово»**.

Общее для всех виджетов:
- заголовок + маленькая кнопка «обновить» + время последнего обновления;
- клик по элементу открывает исходный сервис (Google Calendar / Tasks / Gmail) — нужна понятная аффорданс-иконка «открыть во внешнем»;
- карточки разной высоты — сетка должна выдерживать 0–10+ элементов в списке (с «показать ещё»).

### Командная строка

- Placeholder: «Запиши идею…» / «Capture an idea…».
- В v1 — быстрый ввод идеи (Enter → toast «Идея сохранена»).
- Позже станет входом в голосового/текстового ассистента: предусмотреть место под иконку микрофона и состояние «ассистент думает», но в v1 их не показывать.

## Состояния виджетов

| Виджет | Пусто | Не подключено | Ошибка |
|---|---|---|---|
| События | «Сегодня без встреч — день твой» | — (подключается при входе) | «Не удалось обновить» + повтор |
| Задачи | «Задач на сегодня нет» | — | то же |
| Почта | «Ничего важного» | **«Подключить почту»** — CTA с пояснением, что тела писем не храним | то же |
| Идея дня | «Запиши первую идею» + подсказка про Shortcuts | — | то же |
| AI-сводка | (во время генерации — skeleton текста) | — | скрыть, не ломать экран |

## Мобильная раскладка

- Одна колонка, порядок как выше.
- Командная строка — закреплена вверху или внизу (на выбор дизайнера; учесть удобство большого пальца).
- Стекло на Android будет упрощённым (слабее blur) — дизайн должен оставаться читаемым и с минимальным размытием.

## Языки

Интерфейс — **английский и русский**. Русские строки в среднем на 20–30% длиннее — проверить заголовки, кнопки и чипы на обоих языках.

## Технические ограничения (для реализуемости)

- Реализация: **Expo / React Native + react-native-web**, стили через **NativeWind** (Tailwind). Размытие: `backdrop-filter` в web, `expo-blur` на iOS/Android.
- Шрифт — один семейный (например, Inter или аналог с кириллицей), не более 2–3 начертаний.
- Иконки — один открытый набор (например, Lucide).
- Токены оформить так, чтобы их можно было перенести в `tailwind.config` / `packages/ui`.
